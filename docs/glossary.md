# Glossary

Use these terms in copy, routes and code (UX_PRINCIPLES §2).

| Term           | Meaning                                                                                  |
| -------------- | ---------------------------------------------------------------------------------------- |
| Goal           | The decision a client is trying to make (invest, expand, understand a market)            |
| Research brief | The structured scope built in the goal chat: objective, subjects, questions, constraints |
| Needs summary  | Step 5 of the goal chat, where the client confirms the research brief                    |
| Subject        | A company, region, industry or time frame the research focuses on                        |
| Coverage map   | Per question: Covered / Partly covered / Not covered by library reports, with the reason |
| Library        | Published, expert-backed reports clients can buy with credits                            |
| Report         | One library item, built from expert interviews                                           |
| Custom request | Research commissioned for a client's brief; starts with a quote                          |
| Quote          | Proptyop's offer for a custom request: scope, experts, timeline, credits                 |
| Credits        | The currency clients spend; 1 credit ≈ US$5 in the prototype                             |
| Held credits   | Credits reserved when a quote is accepted; not spendable, not yet spent                  |
| Open call      | A request for experts to give interviews on a topic                                      |
| Interview      | An expert's voice or text session with the AI interviewer                                |
| Expert         | A vetted person who gives interviews; anonymous to clients (role, years, region)         |
| Workspace      | A client's folders and labels for briefs, reports and requests                           |
